# Code of Conduct

Slipcard adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its
code of conduct. It applies in the issue tracker, pull requests, discussions
and anywhere else you represent the project.

In short: be kind, assume good intent, keep criticism about the work and not
the person, and do not harass anyone. People who learn languages come from
everywhere; mistakes in English are welcome here.

## Reporting

Report unacceptable behaviour privately to the maintainer, through the contact
on the maintainer's GitHub profile. Reports are kept confidential. The
maintainer may remove comments, commits, issues or pull requests that break
the code of conduct, and may block people who keep breaking it, following the
Covenant's enforcement guidelines.
